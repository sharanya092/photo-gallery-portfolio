# Bloom Tales

A simple photography portfolio website created with HTML, CSS, and JavaScript.

## About

Bloom Tales is a personal photography portfolio focused on light, nature, everyday moments, and visual storytelling.

## Features

- Responsive photo gallery
- Click-to-enlarge photo lightbox
- About section
- Contact section
- Mobile-friendly design

## Built With

- HTML
- CSS
- JavaScript
